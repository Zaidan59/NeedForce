# NeedForce

![NeedForce Logo](assets/logo.png)

## 📖 Deskripsi

**NeedForce** adalah website komunitas content creator yang terdiri dari 13 anggota profesional yang berkomitmen untuk menghasilkan konten video berkualitas tinggi di berbagai platform digital. Dengan struktur organisasi yang terukur dan tim yang berdedikasi, NeedForce fokus pada pertumbuhan berkelanjutan dan inovasi konten.

## ✨ Fitur

- 🏠 **Halaman Home** - Overview komunitas dan statistik
- 👥 **Halaman Tim** - Profil lengkap anggota tim NeedForce
- 📞 **Halaman Kontak** - Form kontak dan informasi media sosial
- 📊 **Program** - Informasi program dan layanan yang ditawarkan
- 📱 **Responsive Design** - Tampilan optimal di semua perangkat
- 🎨 **Modern UI/UX** - Antarmuka yang menarik dan user-friendly

## 🚀 Teknologi

Project ini dibangun menggunakan:

- **HTML5** - Struktur web
- **CSS3** - Styling dan animasi
- **JavaScript** - Interaktivitas
- **Font Awesome 6.0** - Icon library

## 📊 Statistik Komunitas

- 👨‍👩‍👧‍👦 **13 Anggota** aktif
- 🏢 **4 Divisi** profesional
- 🎬 **24+ Konten** telah diproduksi

## 🎯 Divisi Tim

NeedForce memiliki 4 divisi utama:

1. **Content Creator** - Produksi konten video
2. **Editor** - Editing dan post-production
3. **Designer** - Desain grafis dan visual
4. **Marketing** - Promosi dan strategi

## 💻 Cara Menggunakan

1. **Clone repository**
   ```bash
   git clone https://github.com/Zaidan59/NeedForce.git
   ```

2. **Buka project**
   ```bash
   cd NeedForce
   ```

3. **Jalankan website**
   - Buka file `index.html` di browser
   - Atau gunakan live server untuk development
